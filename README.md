# Personal-Expense-Tracker
A simple CLI-based Python application to track daily expenses. This project demonstrates basic Python concepts including file handling, JSON data structures, and the `datetime` module.

## Features
- Add expenses with amount, category, and description.
- Auto-timestamps for each entry.
- Persistent data storage using a JSON file.
- Clean tabular view of all recorded expenses.
